TEJANO GRILL WEBSITE
=====================

This is a ready-to-upload starter website for Tejano Grill.

FILES
-----
index.html       Main website
styles.css       Design / responsive styling
script.js        Menu category filters + SpotOn order link
images/          Your supplied menu photos

IMPORTANT: SPOTON
-----------------
The Order Online buttons currently use:
YOUR_SPOTON_ORDER_URL

Replace that text in script.js with Tejano Grill's actual SpotOn Order URL.

SpotOn's current online-ordering system connects online orders to SpotOn POS.
A custom direct API integration is possible only through SpotOn's authorized
integration process/API credentials. For the fastest launch, use the restaurant's
SpotOn Order URL.

MENU
----
The website includes a starter transcription from the two menu photos supplied.
Before publishing, verify all item names, prices, modifiers, taxes, hours, and
availability against the live SpotOn menu.

WEB PHOTOS
----------
The featured food photos use remote Unsplash image URLs. If you want, replace
them with Tejano Grill's own food photos for a more authentic site.
